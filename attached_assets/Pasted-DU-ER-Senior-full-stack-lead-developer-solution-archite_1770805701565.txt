6) Cloud storage: Cloudflare R2 (fra start)
=====================================================================
Alle store filer (billeder, PDF, dokumenter) skal i Cloudflare R2.
ALDRIG gem filer i DB.
DB gemmer kun metadata.

R2 adgang:
- Platformens R2 credentials gemmes som server secrets (Replit Secrets / env vars).
- IKKE i UI.
- Kunder skal ikke have R2 keys.

Upload flow:
- Backend genererer presigned upload URL
- Frontend uploader direkte til R2
- Backend gemmer metadata (r2_key, size, mime, checksum, org_id, vehicle_id)
Download flow:
- Backend genererer presigned download URL (org-scoped access control)

Billedpipeline:
- Ved upload: generér thumbnail + web-optimized version (komprimeret)
- Original kun hvis plan tillader (HD storage feature)
- Thumbnails bruges i lister for performance

Storage limits:
- Quota pr plan (GB) + max filer pr bil + max PDF size
- Vis usage i Org settings

Arkivering/lifecycle:
- Når bil er “solgt” og > X dage (fx 90), flyt til “archive path” (billig retention)
- (Valgfrit senere) slet originaler efter X tid for free/trial

Bucket key struktur:
org/{orgId}/vehicle/{vehicleId}/images/...
org/{orgId}/vehicle/{vehicleId}/docs/...
org/{orgId}/vehicle/{vehicleId}/reports/...

9) Core beregninger (skal være korrekte og gennemsigtige)
=====================================================================
A) Total Cost (netto)
TotalCost = købpris + gebyrer + transport + klargøring + syn/plader + øvrige + registreringsafgift
           - moms_retursum (hvis relevant og dokumenteret i scenariet)

B) Resale Scenarios
Compute 3 scenarier:
- Conservative: fx lower percentile/discount
- Normal: median/expected
- Optimistic: upper percentile/premium
Baseret på comps + justering for km/årgang/gear/trim.

C) Profit & ROI
Profit = ResalePrice - TotalCost
ROI% = (Profit / TotalCost) * 100
Break-even Resale = TotalCost

D) MaxBid (smart bud)
MaxBid = NormalResale - tax - (costs excluding purchase) - desired_profit
Vis plads til maxbid: MaxBid - current_price

E) Deal Score 0–100 (med breakdown)
Komponenter:
- Price vs Market (0–40)
- Profit & ROI (0–30)
- Tax/VAT certainty (0–15)
- Sellability (0–10)
- Data quality (# comps) (0–5)
UI skal vise chips der forklarer scoring og top-risici.

F) Risiko-score
Flag:
- Ukendt afgift
- Ukendt moms type
- Lav comp count
- Høj km vs årgang
- Skade/uklar historik
- Høj kapitalbinding

G) “Estimeret vs Faktisk” (V2)
Når solgt:
- indtast faktisk salgspris og faktiske omkostninger
- vis afvigelser og læring
